# Product

DW3CER Save Patch is an operating tool for an owner of a Windows Steam DW3 Remastered save. The primary task is to choose a local file, validate it, review an explicit preset, and download a modified copy with a report and original backup.

Users need predictable Legal Max/Overlimit switching, repeatable patches, correct equipment, and confidence that their source file stays intact. All processing is browser-local. The site is distributed as a static browser application. No private save fixtures, additional proprietary game artwork, telemetry, or fabricated gameplay claims may ship. The existing game favicon remains subject to its owner’s rights.

All interface and documentation copy is American English except the original Chinese title of the 3DM credit and the official Japanese game name in README. No invented product release numbers. Use Vite+, Oxlint/Oxfmt, mise-pinned Node and pnpm, TypeScript 7, and MIT. Keep exactly two primary credits in the interface and README.

Success: validated canonical outputs, no stale download after changing files/options, keyboard-complete flow, and transparent experimental status. No new gameplay patch is silently installed on the user's device.

Keep the website interface simple, with restrained game-inspired colors and frames. Character artwork is reserved for the OG image, not the website UI.
