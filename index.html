Release notes and installation details on GitHub

Install your save safely.

Windows Steam save location. Open this folder in File Explorer:

%LOCALAPPDATA%\KoeiTecmo\DW3CE_RE\Saved\SaveGames

Choose GameStatusData.sav. The browser cannot open this folder for you.

Back up first. Close the game and copy the entire SaveGames folder to a separate location before replacing any files. Keep that backup and download the original backup offered by this tool.

Install a patched save. With the game closed, rename the downloaded patched file to GameStatusData.sav and replace only that file in the save folder. Keep your other save files. Start the game and check your progress and equipment before saving again.

Steam Cloud. Cloud sync can restore or overwrite a local save. Check sync status and temporarily disable this game's Cloud sync when testing a replacement. Resolve any conflict deliberately, then restore your preferred sync setting.

Tested version & limits.

Tested game build. Windows Steam build 25630985 (App 3841510), Windows executable version 1.0.2.0. Acceptance date: October 10, 2026. Save header: Unreal Engine 5.6.1. Other game builds and editions have not been verified.

Verified transformations. Repeated patches and preset switching produce consistent results. Browser output is compared with the native reference engine.

Gameplay boundaries. The initial-save Legal Max and Overlimit candidates were tested in-game by the project owner without reported issues. Overlimit confirmation was recorded on October 11, 2026. Four-element mixing has not been separately tested in-game. Displayed bonuses may exceed effective combat caps.

File validation. DW3CER Save Patch checks structure, version, and references. This save format has no known authenticity signature; validation cannot prove a file’s origin or detect every plausible scalar error.
